# Backend implementation and verification

Implemented Go backend under `backend/`: local-only server with persisted bound port, process lock, random restricted login token, constant-time authentication, HttpOnly SameSite session cookie, cross-origin and CSRF protections; root helper over group-restricted Unix socket; fixed configuration/service/path arguments; installed-binary schema and check; non-destructive drafts, raw JSON preservation, hash conflicts, dependency validation, history restore-to-draft; atomic writes; persistent deployment intent and recovery before helper serves requests; journald SSE with bounded line size and redaction.

The helper owns deployment independently of the web process. systemd must restart the helper after failure. Startup restores an unfinished transaction before accepting requests. Failed recovery keeps the transaction record. Local mode explicitly rejects systemd deployment.

Discovery reads effective systemctl ExecStart and WorkingDirectory. Simple -c/-C/-D and long variants are supported; ambiguous quoting marks read-only. Multiple sources are imported for read-only visual inspection with the installed sing-box merge command and never flattened back to disk. JSONC files are formatted by the installed binary, then comment and trailing-comma trivia are removed for a read-only visual view; original bytes and source hashes remain authoritative. Strict JSON files preserve all JSON fields.

Inspected: official sing-box API/schema documentation; actual sing-box 1.14.4 merge help; generated runtime schema. Files changed: backend/go.mod; backend/internal/core/{core.go,journal.go,core_test.go}; backend/internal/api/{api.go,api_test.go}; backend/internal/web/{web.go,dist/index.html}; backend/cmd/manager/main.go. Root agent owns telemetry and its wiring.
